# Образец: конвейер перевода сборки Linggango

Это **образец готового конвейера** под конкретную сборку — Minecraft 1.20.1,
Forge 47.4.20, 430 модов, FTB Quests с шифрованием `LGQ1:`.

**Не копируй как есть.** Здесь показано, какие куски вообще бывают и как они
связаны между собой. Перепиши под свою сборку: пути, версии, имена неймспейсов,
формат шифрования.

| Файл | Что делает | Что переписать под свою сборку |
|---|---|---|
| `build_resourcepack.py` | собирает `zz_linggango_ru.zip`: полные lang-файлы всех модов + официальный ванильный `ru_ru` + страницы Patchouli; регистрирует пак последним в `options.txt` и `config/linggango-resourcepacks.toml` | пути, имя пака, версию ванильного `ru_ru`, список модов с собственным `ru_ru` |
| `lgq_crypt.py` | шифрование квестов `LGQ1:` — расшифровка, правка, обратное шифрование тем же ключом | **другой алгоритм шифрования** — свой декриптор искать в моде сборки |
| `apply_quests.py` | подстановка переводов в текстовые поля `.snbt` с сохранением id и структуры | формат квестов (в других сборках поля называются иначе) |
| `snbt_text.py` | разбор текстовых полей SNBT (описание квеста — список строк, а не одна) | скорее всего подходит как есть |
| `tr_engine.py` | движок перевода: маскирование §-кодов, плейсхолдеров, тегов, ID, невидимых символов; подстановка терминов глоссария; кэш; валидация | пути к словарям, список брендов, список терминов |
| `verify_all.py` | приёмка: md5 jar, целостность zip, полнота lang-файлов, порядок паков, структура квестов | пути, имя пака, список проверок |

Полный перевод, собранный этим конвейером:
**[`AxopupelBruh/linggango-ru`](https://github.com/AxopupelBruh/linggango-ru)**.

---

## Что здесь ценного

1. **Сборщик ресурспака** — самая хитрая часть: он берёт lang-файлы из jar-ов
   модов, **не перекрывает** непустые чужие переводы, добавляет официальный
   ванильный `ru_ru` целиком и генерирует `ru_ru` для переведённых модов.
2. **Шифрование квестов** — расшифровать → перевести → зашифровать тем же
   ключом, с проверкой round-trip.
3. **Приёмка** — набор проверок, которые ловят ровно те поломки, что описаны
   в `../../docs/TRAPS.md`.
