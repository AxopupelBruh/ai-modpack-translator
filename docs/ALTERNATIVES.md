# Сравнение подходов

К локализации сборок есть три пути. Каждый закрывает свою часть, и они не
взаимозаменяемы.

| | GUI-инструменты («из коробки») | Руками в редакторе | **ИИ-агент + свой конвейер** (этот репозиторий) |
|---|---|---|---|
| Скорость первого прохода | ★★★ | ★☆☆ | ★★☆ |
| Качество русского текста | ★☆☆ кальки | ★★★ | ★★★ (с системным промтом и вычиткой) |
| Защита разметки | ★★☆ частично | ★★★ вручную | ★★★ маскирование токенами |
| Шифрованные квесты | ✗ ломает | ★★★ вручную | ★★★ свой декриптор |
| Добить остатки (не перевести всё) | ✗ | ★★☆ | ★★★ |
| Повторяемость / версионирование | ★☆☆ | ★☆☆ | ★★★ git + словари |
| Цена | бесплатно | часы на мод | токены + часы на настройку |

## Про существующие инструменты

В среде уже есть готовые решения, и они не бесполезны:

| Инструмент | Что умеет | Чем хуже нашего конвейера |
|---|---|---|
| [MineAI-Modpack-Translator](https://github.com/Thedrezik/MineAI-Modpack-Translator) | GUI, 11 языков, маскировка кода, перевод jar-книг и квестов | один размер на всех; не знает формата конкретной сборки; не умеет добить остатки |ть остатки |
| [ru-minetools](https://github.com/k1n1maro/ru-minetools) | GUI, перевод `en_us.json` внутри jar, Patchouli, папки квестов | словарь ~50 терминов вместо десятков тысяч; только Google; **не защищает разметку квестов** (`[gap=5]` → `[пробел=5]`, `{image:…}` ломается); **не умеет шифрование LGQ1**; нет проверок |

**Вывод.** GUI-инструменты хороши для «быстро перевести jar-файлы в один клик»
в простой сборке с открытыми квестами. Они не подходят, когда:

- квесты зашифрованы;
- нужна вычитка и единая терминология;
- надо **добить** чужие переводы, а не заменить их;
- нужен воспроизводимый результат, который не развалится после обновления сборки.

Именно эти задачи и решает подход «ИИ-агент + свой узкий конвейер».

## Почему «ИИ + свой скрипт», а не «ИИ + чужой инструмент»

ИИ отлично знает язык и игровую терминологию, но **не знает формата вашей сборки**:
он не знает, что у вас квесты шифруются, что `$(item)` — это ссылка, а `[gap=5]` —
это отступ, и что полноширинная `。` в китайской книге нарисуется квадратом.

Значит, работу надо разделить:

| Кто что делает | Почему так правильно |
|---|---|
| **ИИ** переводит текст | знает язык, терминологию, официальный перевод ванилы |
| **Скрипт** защищает формат | знает формат вашей сборки и не отдаёт движку то, что ломать нельзя |
| **Скрипт** собирает и проверяет | может проверить то, что человек eyeball'ом не заметит: 0 потерянных плейсхолдеров, полнота lang-файлов, совпадение id квестов |

Отсюда правило: **ни одной строки не отдаётся переводчику напрямую**. Всё, что
может сломаться (§-коды, плейсхолдеры, теги, ID, бренды, невидимые символы),
сначала маскируется токенами и возвращается на место после перевода.

## Когда что применять

- **Сборка уже переведена сообществом** (есть MPLOCmods и подобные) → сценарий
  «поставить → снять остатки → перевести остатки». Это 80 % работы и экономия
  лимитов.
- **Сборка без переводов, простая, квесты открытые** → можно взять GUI-инструмент,
  сэкономив время на своём скрипте. Риск: разметка поедет — проверяй глазами.
- **Квесты зашифрованы, модов много, нужна терминология** → только свой конвейер.
- **Нужна воспроизводимость** (обновление сборки, откат, ревью) → git + словари.

## Что в этом репозитории уже работает

- `docs/GUIDE.md` — метод целиком, от разведки до приёмки.
- `docs/TRAPS.md` — 20 ловушек с симптомом и решением.
- `docs/UPGRADES.md` — что переживёт обновление сборки.
- `prompts/SYSTEM_PROMPT_EN_RU.txt` — промт переводчика, проверен на 8 000 строк.
- `scripts/` — переносимые куски (парсеры, бэкенды, аудиты).
- `reference/lingtango/` — образец целого конвейера на реальной сборке.
- `templates/` — заготовки для публикации своего перевода.
