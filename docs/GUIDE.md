# Гайд по локализации сборки Minecraft с помощью ИИ

Универсальный промт для ИИ-агента. Подходит к любой сборке **1.16–1.21**.
Метод отработан на сборке **LIngango** (430 модов, 1.20.1, Forge) — полный перевод
в репозитории [`AxopupelBruh/linggango-ru`](https://github.com/AxopupelBruh/linggango-ru).

> **Как пользоваться:** скорми этот файл ИИ-агенту вместе с путём к инстансу сборки
> и с системным промтом из `prompts/SYSTEM_PROMPT_EN_RU.txt`. Агент читает и работает
> по нему. Сначала он задаст тебе три вопроса (§1) — ответь, дальше он пойдёт сам.

---

## 0. РОЛЬ АГЕНТА

Ты — технический переводчик игровых локализаций. Задача: **довести русский язык
в сборке до конца**, не сломав игру и не испортив дизайн.

Ты работаешь с живой игрой, поэтому:

- **Никогда не патчи jar-файлы модов.** Сборка обновляется через CurseForge — патч пропадёт.
  Всё через ресурспак, датапак и скрипты.
- **Никогда не ломай формат.** Сломанный lang-файл = мод крашится или показывает
  английский. Сломанный файл квестов = пропала глава. Сломанная картинка = артефакт в игре.
- **Никогда не переводи то, что не текст.** ID предметов, бренды модов, команды, ссылки.

## 1. ПЕРВЫЙ ВОПРОС ПОЛЬЗОВАТЕЛЮ (обязательно)

Прежде чем что-либо делать, **спроси пользователя** — от ответа зависит всё остальное:

1. **Чем переводить:**

   | Вариант | Оценка | Комментарий |
   |---|---|---|
   | A. Google Translate | ⭐ очень плохо | Кальки, ломает терминологию. Только для оценки объёма. |
   | B. DeepL | ⭐⭐ лучше, но плохо | Читаемый русский, но без знания контекста Minecraft. Ломает падежи. |
   | C. Нейронка с системным промтом | ⭐⭐⭐ **лучший** | Знает официальный перевод Minecraft, склоняет термины, держит §-коды. |

   **Рекомендация — C.** Готовый промт: `prompts/SYSTEM_PROMPT_EN_RU.txt`.
   DeepL — как **запасной** бэкенд, когда основной движок отваливается.

2. **Объём:** только остатки (то, что после чужих переводов осталось на английском)
   или всё подряд с нуля.

3. **Нужно ли трогать картинки** (плоский 2D-текст в PNG) — по умолчанию да, объёмные
   3D-логотипы модов — нет.

**Не начинай перевод, пока не ответил на (1).**

## 2. ЖЕЛЕЗНЫЕ ПРАВИЛА (нарушение = поломка)

1. **Jar-файлы модов не трогаем.** Только внешние слои: ресурспак, датапак, скрипты.
2. **Наш ресурспак — ПОСЛЕДНИМ** в `options.txt` и в `config/*resourcepacks.toml`.
3. **Lang-файлы ресурспака ЗАМЕНЯЮТ файлы модов целиком, а не мержатся.**
   ⚠️ Главная ловушка: если в паке лежит `assets/<ns>/lang/ru_ru.json` с одной строкой —
   мод потеряет **все** свои русские переводы. То же с ванилой:
   `assets/minecraft/lang/ru_ru.json` должен содержать **все** ~8800 ключей, иначе весь
   ванильный интерфейс уйдёт в английский. **Клади в пак только ПОЛНЫЕ lang-файлы.**
4. **Бренды и названия модов — латиницей** (Create, Mekanism, FTB, JEI, Ars Nouveau…).
   Маскировать перед переводом, восстанавливать после.
5. **§-коды, `&`-коды, hex-цвета, теги, плейсхолдеры, ID, URL — не переводить.**
   Маскировать токенами и возвращать на место.
6. **Чужие (общинные) переводы не переопределяем нашими**, если они уже корректные.
   Перекрываем только пустые/английские значения. Если у мода есть **собственный
   `ru_ru.json`** — это его вычитка, не трогай её (кроме пустых значений).
7. **Картинки:**
   - **объёмный 3D-текст (логотипы модов, ~99 %) — НЕ ПЕРЕВОДИМ.** Это бренды.
   - **плоский 2D-текст (подписи, заголовки, схемы, карточки) — ПЕРЕВОДИМ.**
   - При перерисовке PNG **сохраняем**: размер холста, палитру, градиент заливки,
     цвет обводки, свечение, тени, позиционирование. Цвет и стиль — часть дизайна.
8. **Числа — с точкой, не с запятой** (`110.0`, не `110,0`) — иначе ломается подстановка.
9. **Никаких готовых «локализаторов из коробки».** Чужие инструменты, которые правят
   lang-файлы и квесты, не зная формата конкретной сборки, **ломают их**. Свой узкий
   скрипт под конкретную сборку + проверка результата — единственный надёжный путь.
10. **Символ должен иметь глиф в шрифте игры.** Иероглифы, `➤`, `（`, эмодзи без
    поддержки в шрифте рисуются пустым квадратом. Проверяй скриптом
    `scripts/audit_font_coverage.py` (§9).

## 3. РАЗВЕДКА СБОРКИ (шаг 0 — до перевода)

Найди инстанс. Для CurseForge это обычно
`~/.local/share/PrismLauncher/instances/<name>/` или `~/Documents/curseforge/minecraft/Instances/<name>/`.

Собери факты и **покажи их пользователю**:

```bash
python3 scripts/audit_pack.py <инстанс>          # всё сразу: версии, объём, риски
python3 scripts/audit_pack.py <инстанс> -o work/RECON.md --json work/recon.json
```

Скрипт читает только файлы, ничего не меняет, и сразу делит найденное на то,
что можно переводить, и на то, что сломается. Если нужно вручную:

```bash
cd <инстанс>
ls mods/*.jar | wc -l                          # сколько модов
ls config/                                     # какие моды с конфигами
ls config/ftbquests/quests/chapters/           # квесты FTB
ls kubejs/ config/openloader/                  # скриптовые моды
ls resourcepacks/                              # уже стоящие пакеты
grep -o '"file/[^"]*"' options.txt | tail -5    # порядок паков
```

Определи по содержимому:

| Что | Где искать | Что делаем |
|---|---|---|
| Квесты FTB | `config/ftbquests/quests/**.snbt` | переводим текст, id не трогаем |
| Квесты FTB (зашифр.) | файл начинается с `LGQ1:` или другого магического префикса | **нужен декриптор**; если его нет — спросить пользователя |
| Книги Patchouli | внутри jar: `assets/<ns>/patchouli_books/` | переводим страницы |
| Книги в данжах | `datapacks/`, `saves/*/datapacks/`, лут-таблицы в jar | ищем `.json` с текстом |
| Скрипты KubeJS | `kubejs/**/*.js` | строки в UI |
| Свои ru_ru у модов | `assets/<ns>/lang/ru_ru.json` внутри jar | не переопределять вычитку мода |
| Захардкоженный текст | `ru_ru` есть, а UI английский | см. `HARDCODED.md`, разбор через `dump_hardcoded.py` |

## 4. СЛОИ ПЕРЕВОДА — ЧТО И КАК

| Слой | Где лежит | Как переводим |
|---|---|---|
| **Lang-файлы модов** | `assets/<ns>/lang/en_us.json` в jar | полный `ru_ru.json` в ресурспак |
| **Ванильный интерфейс** | `assets/minecraft/lang/ru_ru.json` | полный официальный файл (для 1.20.1 — 8799 ключей) |
| **Строки из Java-кода** | `.class` внутри jar | скан + перевод; применить скриптом-перехватчиком тултипов |
| **Подсказки предметов** | формируются в коде | скрипт на `ItemTooltipEvent` (KubeJS / Architectury) |
| **Квесты FTB** | `config/ftbquests/quests/**` | правка текстовых полей, id/координаты не трогаем |
| **Книги Patchouli** | `assets/<ns>/patchouli_books/<book>/ru_ru/` | страницы; макросы `$()` не трогаем |
| **Книги в данжах** | датапаки, лут-таблицы | JSON с текстом, структуру сохраняем |
| **Скрипты KubeJS** | `kubejs/**` | строки-плейсхолдеры |
| **Картинки** | `kubejs/assets/`, `assets/` в jar | только плоский 2D-текст |

## 5. ГЛАВНЫЙ СЦЕНАРИЙ: «ПОСТАВЬ РЕСУРСПАК, ПОТОМ ДОБЕРИ ОСТАТКИ»

```
ШАГ 1. Найти и поставить существующие пакеты локализации (чужие)
ШАГ 2. Наш пак — ПОСЛЕДНИМ в options.txt и в toml
ШАГ 3. Запустить игру и пройти сборку (квесты, JEI/REI, инвентарь, данжи)
ШАГ 4. Снять ОСТАТКИ: что после чужих переводов всё ещё на английском
ШАГ 5. Перевести остатки (только их)
ШАГ 6. Пересобрать, перепроверить
```

**Почему нельзя сразу «перевести всё»:** сборка обычно уже частично переведена.
Перевод с нуля портит вычитку и тратит лимиты. Содержательная работа — **добить**,
а не заменить.

**Что поставить в шаге 1:** ищи пакеты, которые уже есть для этой сборки:
[MPLOCmods](https://www.curseforge.com/minecraft/texture-packs/mplocmods) (2300+ неймспейсов),
MPMods, «Fabric Language Pack», локализации отдельных авторов. Проверь на CurseForge.

### 5.1. Как снять остатки (шаг 4)

**A. Lang-файлы.** Нужны ключи, где `en_us` есть, а `ru_ru` отсутствует или пуст.
Скан по jar: для каждого `assets/<ns>/lang/en_us.json` сравни с тем, что покрывают
установленные пакеты + наш пак. Результат — список `[ns, key, english]`.

**B. Runtime-строки.** Включи логирование клиента, запусти игру, пройди всё интересное.
Ищи в логе строки, которые движок перевода не знает (в Linggango это метка `[RU-TT]`
в `logs/kubejs/client.log`).

**C. Квесты.** Пройди все главы и ищи английский текст в описаниях/заголовках.

**D. Картинки.** Просканируй PNG на английский текст (OCR) и отфильтруй мусор
словарём английских слов из lang-файлов. Затем отсортируй вручную:
плоский 2D (переводим) vs объёмный 3D (не переводим).

## 6. ФОРМАТЫ, КОТОРЫЕ ОБЯЗАНЫ ВЫЖИТЬ

### 6.1. Lang-файлы
```json
{ "item.minecraft.diamond_sword": "Алмазный меч", "block.minecraft.stone": "Камень" }
```
Плоский словарь, ключ = путь, значение = текст. Значения могут содержать `§`-коды.
Minecraft допускает JSON с комментариями — парсер должен это учитывать
(`scripts/lang_json.py`).

### 6.2. Квесты FTB
**Описание квеста — это СПИСОК строк**, а не одна строка:
```
description: [
    "первая строка"
    "вторая строка"
]
```
Заголовок — одиночная строка. Переводить только поля `title`, `subtitle`, `description`,
`objective`, `name`.

**Не трогать:** `id`, `group`, `autofocus_id`, `filename`, `icon`, координаты (`x`,`y`),
`rotation`, `alpha`, `width`, `height`, `order`, `dependency`.

**Разметка внутри строк (переводить НЕЛЬЗЯ — игра сама разбирает маркеры):**
```
{image:ns:path width:.. height:.. align:..}    вставка картинки
[gap=N]                                        отступ
[!tip] [!info] [!danger] [!warning] [!success] [!note]
[details]…[/details] [spoiler] [center]
[progress] [progress=HEXID]
[item:…] [entity:…] [task:…] [quest:…] [link:…] [copy:…] [cmd:…] [hover:…] [key:…] [lang:…]
[ff0000]                                       hex-цвет
```

**Форматирование Minecraft:** `§`-коды (`§7`, `§b`, `§4`), `&`-коды, hex `#RRGGBB`,
теги `<typewriter>`, `<grad from=#F0B23A to=#FFF0CC f=0.6>`, `<shadow a=0.4>`, `<click>`.

**Невидимые разделители ZWNJ (U+200C)** — встречаются в разных сборках.
Правило: слово + ZWNJ + **ровно один** пробел + следующее слово. Машины этот маркер
растаскивают («ZWNJ + два пробела», «пробел + ZWNJ») — в игре видны лишние пробелы.
Если в сборке есть ZWNJ — нормализуй после перевода.

**Экранирование SNBT:** `\"` и `\\` сохранять как есть.

⚠️ **Перед правкой квестов — полный бэкап каталога.** И **после** — проверка, что
FTB Quests читает файлы (собрать книгу в игре). Если сборка шифрует квесты —
правка открытым текстом ломает главы целиком.

### 6.3. Подсказки предметов
Тултипы формируются в коде мода. Переводятся через:
- **скрипт** с перехватом события тултипа (Forge `ItemTooltipEvent`,
  Architectury `ItemEvents.tooltip`) — работает и в JEI/REI;
- либо патч мода (**требует разрешения владельца**).

Ключевая сложность — **шаблоны**: одна и та же фраза с разными числами.
`%d HP у %s` → шаблон `§7%d HP у %s`. Переводить один раз, подставлять числа динамически.
Плейсхолдеры должны совпадать **посимвольно** — иначе игра падает.

### 6.4. Книги Patchouli
`assets/<ns>/patchouli_books/<book>/ru_ru/...`. Макросы `$(l:ns:path)`, `$(item)`,
`$(br)`, `$(crafting_table)` — **не переводить**, это ссылки.

### 6.5. Датапаки (книги в данжах)
JSON-файлы с текстом + `pack.mcmeta`. Лут-таблицы тоже могут содержать текст —
их нужно переводить, сохраняя структуру JSON. ⚠️ Датапак **заменяет** файл целиком:
если мод обновится, наш старый датапак перекроет его новую лут-таблицу (см. `UPGRADES.md`).

### 6.6. Картинки (PNG) — что сохранять при перерисовке
Сними параметры с оригинала до правки, затем воспроизведи:
размер холста и позиционирование; вертикальный градиент заливки; «inline»-обводку
и внешний контур; 3D-объём (тёмная смещённая копия силуэта); свечение; альфа-канал.

Пример снятых параметров (заголовок акта, 2056×191):
| Слой | Значение |
|---|---|
| Лицо | вертикальный градиент `(247,212,103)` → `(229,182,59)` |
| Inline-обводка | кремовая `(208,204,149)`, alpha ≈ 113, ~3 px |
| Внешний контур | чёрный `(14,18,26)`, ~2 px |
| 3D-объём | копия силуэта со сдвигом **(+13, +13)**, тёмно-зелёный |
| Свечение | мягкое радиальное вокруг букв |

**Пиксельный шрифт с кириллицей:** Monocraft (v4.2.1, полная кириллица, 1475 глифов) —
<https://github.com/IdreesInc/Monocraft/releases>
⚠️ Встроенный шрифт **Aseprite** не подходит: его битмап-спрайтшит (16×72 ячеек по 11 px)
содержит только ASCII, кириллицы в нём нет, а fallback уходит в системный DejaVu
(не пиксельный).

### 6.7. Шрифт игры — отдельный слой
**Класть свой шрифт в ресурспак не нужно.** Ванильный шрифт 1.20.1 уже покрывает всю
кириллицу: `nonlatin_european.png` (А–Я, а–я) + `accented.png` (Ё/ё и ещё ~1200 символов).
Свой шрифт изменит вид всего интерфейса и конфликтует с паками, у которых есть
`assets/minecraft/font/default.json`.

Но проверить покрытие стоит: `scripts/audit_font_coverage.py` покажет символы,
которые рисуются пустым квадратом, и где они лежат.

## 7. ТЕРМИНОЛОГИЯ — ПРИОРИТЕТЫ

1. **Официальный ванильный `ru_ru`** — высший приоритет. Скачай с ассет-стора Mojang
   (`resources.download.minecraft.net`) для нужной версии. Из него получается ~4 700
   терминов (Ice→Лёд, Sculk→Скалк, Netherite Ingot→Незеритовый слиток).
   ⚠️ Возьми `ru_ru` для **1.20.1**, даже если сборка новее: ключи стабильны,
   лишние безвредны.
2. **Глоссарий сборки** (термины из lang-файлов + словарь модов) — второй приоритет.
   Подставляй термины как **защищённые токены**: модель обязана их употребить,
   но **склонять по-русски** («эффект Божественного возмездия»).
3. **Уже переведённое в проекте** — не переводить заново, а дополнять.

⚠️ Известный конфликт: mined-глоссарий даёт «Удача», официальная ваниль — «Везение».
Приоритет у ванили.

## 8. ПАЙПЛАЙН ПЕРЕВОДА

```
1. Разведка сборки (§3) → показать пользователю
2. Спросить движок (§1) → получить ответ
3. Поставить чужие пакеты + наш пак последним (§5, шаги 1-2)
4. Запустить игру, снять остатки (§5.1)
5. Классифицировать: переводим / не переводим (§2.7)
6. Замаскировать: теги, §/&, hex, %s/%d, {0}, URL, ns:path, /команды,
   невидимые символы, макросы $(), разметка квестов {} [], бренды
   → токены [[0]][[1]]…
7. Подставить термины глоссария → тоже под токенами
8. Перевести пачкой выбранным движком
9. Снять токены, восстановить коды/бренды
10. Валидировать: плейсхолдеры на месте, непусто, есть кириллица,
    §-коды (допускать перестановку цветов и лишний код в конце)
11. Записать в словари, собрать ресурспак/датапак/скрипт
12. Проверить по критериям §10
```

**Кэш обязателен:** не переводи одну строку дважды. Хранить `cache_<движок>.json`.
При повторных прогонах лимит не тратится.

⚠️ **Кэш должен покрывать все строки.** Если кэш урезался (а он урезается при
ручных правках), следующая пересборка молча потеряет переводы. Проверяй:
`всего страниц: N, без перевода в кэше: 0`.

## 9. ИНСТРУМЕНТЫ

**Готовые «локализаторы из коробки» использовать нельзя.** Инструменты, которые правят
lang-файлы и квесты, не зная формата конкретной сборки, **ломают их**.

Надёжный путь — **написать свой узкий скрипт под конкретную сборку**, опираясь на
форматы из §6, и проверять результат по критериям §10.

В `scripts/` лежат переносимые куски, которые **работают как есть** или требуют
только смены путей:

| Скрипт | Для чего |
|---|---|
| `audit_pack.py` | **разведка одной командой**: версии, объём по слоям, что уже переведено, шифрование квестов, книги, порядок паков, риски |
| `check_translation.py` | **валидатор перевода**: плейсхолдеры, `§`-коды, токены, пунктуация, регистр, непереведённое. `error` / `warn` / `info` |
| `dump_hardcoded.py` | разбор мода на захардкоженный текст (constant pool + `javap` для подсчёта вызовов) |
| `lang_json.py` | терпимое чтение lang-файлов (BOM, комментарии, висячие запятые) |
| `snbt_text.py` | разбор и подстановка текстовых полей в SNBT квестов |
| `brands.py` | маскирование и восстановление брендов (список — свой) |
| `deepl_backend.py` | бэкенд DeepL (ключ из `.deepl_keys` рядом со скриптом) |
| `deepseek_backend.py` | бэкенд DeepSeek/OpenAI-совместимого API; правила читает из `prompts/SYSTEM_PROMPT_EN_RU.txt` |
| `build_tooltip_script.py` | сборка KubeJS-переводчика подсказок |
| `collect_text_png.py` | поиск PNG с английским текстом + галерея (`root out`) |
| `audit_font_coverage.py` | символы без глифа в шрифте игры |

В `reference/lingtango/` — образец целого конвейера под конкретную сборку
(сборка ресурспака, шифрование квестов, приёмка). **Перепиши под свою сборку**,
не копируй как есть.

В `prompts/` — промты под каждый режим работы:

| Файл | Когда |
|---|---|
| `SYSTEM_PROMPT_EN_RU.txt` | перевод строк; единственный источник правил, `deepseek_backend.py` читает его из файла |
| `AUDIT_PROMPT.txt` | найти брак в готовом переводе (непереведённое, сломанная подстановка, калька, термины) |
| `PROOFREAD_PROMPT.txt` | вычитка стиля: канцелярит, порядок слов, род, повторы |
| `RECON_PROMPT.txt` | разведка сборки до начала перевода |

Системные утилиты, которые безопасны:

| Утилита | Для чего |
|---|---|
| `python3` + `Pillow` | чтение/запись PNG, измерение палитры, построение градиентов |
| `python3` + `fontTools` | проверка charset шрифта (есть ли кириллица) |
| `tesseract` | OCR: найти английский текст на картинках |
| ImageMagick (`convert`, `montage`) | конвертация, контактные листы для ручного отбора |
| `javap` / `unzip` | просмотр строк внутри `.class` и `.jar` |
| `requests` | запросы к API переводчиков |

Сканирование `.class` на строки:
```bash
javap -c -p ModClass.class | grep -oE 'String [^ ]+'
```

## 11. ШПАРГАЛКА КОМАНД

```bash
# разведка
python3 scripts/audit_pack.py <инстанс>          # всё сразу + риски
ls mods/*.jar | wc -l; ls config/; ls resourcepacks/
grep -o '"file/[^"]*"' options.txt | tail -5

# ванильный ru_ru (для своей версии)
curl -sO https://resources.download.minecraft.net/v1_20_1/assets/minecraft/lang/ru_ru.json

# поиск английских строк в class-файлах
javap -c -p <Class>.class | grep -oE 'String [^ ]+'

# захардкоженный текст: разбор мода и оценка объёма
python3 scripts/dump_hardcoded.py mods/<мод>.jar -o HARDCODED.md

# OCR по PNG
tesseract file.png stdout -l eng --psm 11

# поиск картинок с текстом по всей сборке
python3 scripts/collect_text_png.py <инстанс> ./png-scan

# символы без глифа в шрифте
python3 scripts/audit_font_coverage.py <инстанс> --font-json <путь к include/default.json>

# проверка перевода до сборки
python3 scripts/check_translation.py work/mods_ru.json            # блокеры
python3 scripts/check_translation.py work/mods_ru.json --all      # + стилистика
python3 scripts/check_translation.py pack.zip --mods mods/        # по готовому паку

# сборка и проверка ресурспака
python3 build_resourcepack.py
python3 verify_all.py

# проверка целостности zip
python3 -c "import zipfile; print(zipfile.ZipFile('pack.zip').testzip())"
```
