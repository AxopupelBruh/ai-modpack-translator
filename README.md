# Перевод сборок Minecraft с помощью ИИ

Метод и инструменты для того, чтобы **довести русский язык в сборке до конца**:
интерфейс модов, подсказки предметов, квесты, книги — и не сломать игру при этом.

Метод отработан на сборке **LIngango** (430 модов, Minecraft 1.20.1, Forge) —
полный перевод лежит в репозитории **[`AxopupelBruh/linggango-ru`](https://github.com/AxopupelBruh/linggango-ru)**:
285 неймспеймов, 46 160 переводов, 23 952 квеста, 8 916 строк подсказок.

> **Перевод в Linggango выполнен при помощи ИИ.** Так же и здесь: гайд, промты
> и скрипты — это то, чем ИИ-агент работает над сборкой.

---

## Быстрый старт

1. Скопируй `docs/GUIDE.md` и `prompts/SYSTEM_PROMPT_EN_RU.txt`.
2. Дай ИИ-агенту эти два файла и путь к инстансу сборки.
3. Агент задаст три вопроса (движок перевода, объём, картинки) — ответь.
4. Дальше он сам: разведка → установка паков → аудит остатков → перевод →
   сборка → приёмка.

Или вручную:

```bash
# 1. что осталось на английском
python3 scripts/collect_text_png.py <инстанс> ./png-scan   # картинки с текстом
python3 scripts/audit_font_coverage.py <инстанс> --font-json <include/default.json>

# 2. перевести (промт — в prompts/, бэкенды — в scripts/)
# 3. собрать и проверить
python3 build_resourcepack.py
python3 verify_all.py
```

## Главное, что нужно знать до начала

**1. Lang-файл ресурспака ЗАМЕНЯЕТ файл мода, а не мержит.**
Если положить в пак `assets/<ns>/lang/ru_ru.json` с одной строкой — мод потеряет
**весь** свой русский перевод. То же с ванилой: `assets/minecraft/lang/ru_ru.json`
должен содержать все ~8800 ключей, иначе весь интерфейс игры уйдёт в английский.
Клади в пак только **полные** lang-файлы.

**2. Наш ресурспак — последним в списке.** Он имеет высший приоритет.
Если поставить раньше — его перекроет чужой пак; если чужой позже — он перекроет наш.

**3. Jar-файлы модов не патчатся.** Сборка обновляется через CurseForge, патч пропадёт.
Весь перевод — во внешних слоях: ресурспак, датапак, скрипты.

**4. Ни одной строки не отдаётся переводчику напрямую.** Всё, что может сломаться
(`§`-коды, плейсхолдеры, теги, ID, бренды, невидимые символы), сначала
маскируется токенами и возвращается на место после перевода.

**5. Чужие переводы не портим.** Если мод уже даёт корректный русский — оставляем.
Перекрываем только пустые и английские значения.

Полный список — в [`docs/TRAPS.md`](docs/TRAPS.md): 20 ловушек с симптомом и решением.

## Слои перевода, которые покрывает метод

| Слой | Как |
|---|---|
| Lang-файлы модов | полный `ru_ru.json` в ресурспак, ключ = путь |
| Ванильный интерфейс | полный официальный `ru_ru` нужной версии |
| Строки из Java-кода | скан `.class` + перехватчик тултипов (KubeJS → Architectury → Forge) |
| Квесты FTB Quests | правка текстовых полей, id/координаты не трогаем, шифрование — своим ключом |
| Книги Patchouli | страницы, макросы `$(...)` не трогаем |
| Книги в данжах | датапак, перекрывающий лут-таблицы |
| Скрипты KubeJS | строки-плейсхолдеры |
| Картинки | только плоский 2D-текст; 3D-логотипы — бренды |

## Промт переводчика — что внутри

`prompts/SYSTEM_PROMPT_EN_RU.txt` учитывает:

- **официальный русский перевод Minecraft** — высший приоритет (`Ice → Лёд`,
  `Sculk → Скалк`, `Netherite Ingot → Незеритовый слиток`);
- **падежи и согласование** — «повышает максимальное здоровье», а не
  «Увеличивает Вашу Максимальную Здоровье»;
- **бренды латиницей** — FTB, JEI, Create, Mekanism, Ars Nouveau и любые другие;
- **§-коды, плейсхолдеры, единицы измерения** — не трогать, числа с точкой;
- **игровые термины** — Зачарования, Снаряжение, Эффект, Флюид, Сеть…

## Требования

```bash
pip install pillow fonttools requests        # для картинок, шрифтов и API
apt install tesseract-ocr imagemagick        # OCR и контактные листы
```

Остальное — стандартная библиотека Python 3.10+.
