## Что переведено

| Слой | Что именно | Объём |
|---|---|---|
| **Ресурспак** | lang-файлы всех модов, страницы книг Patchouli, ванильный `ru_ru` | {{ФАЙЛОВ}} файлов, {{НЕЙМСПЕЙСОВ}} lang, {{КЛЮЧЕЙ}} ключей |
| **KubeJS-скрипт** | подсказки предметов, которых нет в lang-файлах | {{СТРОК}} строк |
| **Квесты FTB Quests** | заголовки, описания, подзаголовки, подсказки квестов | {{ФАЙЛОВ_КВЕСТОВ}} файлов, {{КВЕСТОВ}} квестов |
| **Книги в данжах** | страницы книг прямо в лут-таблицах | {{СТРАНИЦ}} страниц |

### Что сознательно НЕ переведено

- **Объёмный 3D-текст на картинках** (логотипы модов) — это бренды.
- **GUI-экраны с зашитым в код текстом.**
- **Строки в JSON-конфигах модов** (не в `lang/`) — их перевод ломает конфиги.
- **Иероглифы и эмодзи из оригинальных английских строк** — оставлены как у авторов модов.

## Установка

### Шаг 1. Базовый ресурспак — обязательно

Наш перевод **добивает** уже существующие переводы, а не заменяет их.
Фундамент: {{ССЫЛКА_НА_БАЗОВЫЙ_ПАК}}.

> **Последняя версия всегда на CurseForge.** Копия в этом репозитории может
> отставать — так вы получите свежие переводы от сообщества, а наш пак перекроет
> только то, что ещё не переведено.

Как поставить: скачать `.zip` → `<инстанс>/resourcepacks/`.

### Шаг 2. Наш ресурспак — обязательно

`install/resourcepacks/{{ИМЯ_ПАКА}}.zip` → `<инстанс>/resourcepacks/`.

**Порядок паков важен.** Наш пак должен быть **последним**: lang-файл ресурспака
**заменяет** файл мода целиком, а не мержится с ним.

```
Ресурспаков: ...,file/{{БАЗОВЫЙ}}.zip,file/{{НАШ}}.zip
```

### Шаг 3. Скрипт подсказок — обязательно

`install/kubejs/client_scripts/ru_tooltip_translator.js` →
`<инстанс>/kubejs/client_scripts/`.

### Шаг 4. Переведённые квесты — обязательно

`install/config/ftbquests/quests/` → `<инстанс>/config/ftbquests/quests/`.

⚠️ **Перед копированием сделайте копию своей папки квестов** — см. раздел
про обновление сборки.

### Шаг 5. Книги в данжах — по желанию

`install/mods/{{ИМЯ_МОДА_С_КНИГАМИ}}.jar` → `<инстанс>/mods/`.

**Этот мод не обязателен.** Он не добавляет геймплея. Это перекрытие
лут-таблиц датапаком: в сундуках данжей лежат книги, страницы которых зашиты
прямо в JSON лут-таблицы — ни ресурспак, ни KubeJS их не трогают.

### Шаг 6. Язык игры

В `options.txt` должно быть `lang:ru_ru`.

## Устойчивость к обновлению сборки

Перевод сделан через ресурспак, датапак и KubeJS — **jar-файлы модов не патчатся**.
Поэтому переживает обновление лучше, чем «зашитый» в мод перевод.

**Что не сломается:** переводы модов и подсказки. Мод обновился — наш
`ru_ru.json` продолжает перекрывать его lang-файл.

**Что может сломаться:**

1. **Квесты** — если автор изменит ключ шифрования, файлы перестанут расшифровываться.
   *Делать:* копия `config/ftbquests/quests/` перед обновлением; новую папку
   перешифровать заново; крайний вариант — удалить переведённые `.snbt`.
2. **Датапак книг** — он заменяет лут-таблицу целиком, и при обновлении мода
   перекроет его новую версию. *Делать:* пересобрать датапак; до этого — jar
   лучше удалить.
3. **Новые ключи** у обновлённых модов останутся английскими — лечится повторным
   прогоном перевода.

**Что не переведётся никогда:** текст в GUI-коде, картинки, строки в конфигах.

## Структура репозитория

```
install/       ← копируется в корень инстанса сборки
data/          ← итоговые словари «английский → русский»
docs/          ← гайд и план работ
tools/         ← скрипты, которыми сделан перевод
```

## Как дописать перевод

```bash
cd tools/
python3 collect.py                 # собрать остатки
python3 run.py --source mods --out mods_ru   # перевести
python3 build_resourcepack.py      # собрать ресурспак
python3 verify_all.py              # проверить → «ВСЁ ОК»
python3 publish_release.py --push  # собрать и залить репозиторий
```

## Авторство

Перевод сделан сообществом. Тексты модов, названия и иконки принадлежат их
авторам; этот репозиторий содержит только перевод.
